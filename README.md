# OpenRCT2-Ride-Stall-Throughput-Price-Notifier-Plugin
A plugin for OpenRCT2 which notifies whenever guests think a ride is too expensive or too cheap. Also notifies whenever a ride has a lower throughput of guests than expected. This plugin helps you focus on building your park instead of having to check rides and stalls often to see if they're making money and doesn't feel like a cheat.
